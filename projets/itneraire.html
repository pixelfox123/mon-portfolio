🌐 ITnéraire — Mon site web

ITnéraire est un site personnel à vocation professionnelle que j'ai créé pour présenter mon parcours, mes réalisations, mon laboratoire et ma veille technologique.

🎯 Objectif du projet

Concevoir un site web moderne, accessible sur ordinateur et sur téléphone, afin de présenter mes compétences et mon évolution dans les domaines des systèmes, des réseaux et de la cybersécurité.

💻 Technologies utilisées

  • HTML : structure des pages
  • CSS : design et adaptation mobile
  • JavaScript : interactions
  • VS Code : environnement de développement

🐙 Git et GitHub

J'utilise Git pour suivre les modifications de mon projet et GitHub pour héberger mon dépôt de code source.

Chaque nouvelle version est enregistrée avec un commit, puis envoyée vers GitHub grâce à la commande git push.

☁️ Cloudflare Pages

Mon site est hébergé sur Cloudflare Pages, un service permettant de publier des sites web statiques.

Le dépôt GitHub est connecté à Cloudflare Pages. Lorsqu'une nouvelle version est envoyée sur la branche main, un nouveau déploiement est automatiquement lancé.

🚀 Les étapes de réalisation

  • Création de la structure HTML des différentes pages.
  • Personnalisation du design avec un thème futuriste cyan et violet.
  • Adaptation de l'affichage aux écrans mobiles.
  • Mise en place du suivi des modifications avec Git.
  • Publication du code sur GitHub.
  • Configuration du déploiement automatique avec Cloudflare Pages.

🧠 Compétences développées

Ce projet m'a permis de pratiquer le développement web, l'organisation de fichiers, l'utilisation de Git et GitHub, ainsi que la mise en ligne et la maintenance d'un site web.
