🔐 Veille technologique

Dans le cadre de ma formation de Technicienne Supérieure Systèmes et Réseaux, je m'intéresse aux évolutions de l'informatique et de la cybersécurité. Voici une sélection de sujets que je suis.

🛡️ Les ransomwares

Les ransomwares sont des logiciels malveillants capables de bloquer l'accès aux données d'une organisation. Les sauvegardes déconnectées, les mises à jour et la sécurisation des accès sont essentielles pour limiter les risques.

🐧 Les vulnérabilités Linux

Le CERT-FR publie régulièrement des alertes concernant les vulnérabilités des systèmes Linux. Certaines failles peuvent permettre une élévation de privilèges ou perturber les services. Il est donc important de suivre les correctifs.

🐘 Les vulnérabilités PHP

Le 22 octobre 2026, Cybermalveillance.gouv.fr a publié une alerte concernant deux failles de sécurité critiques dans PHP, un langage utilisé pour développer des sites et applications web. Ces vulnérabilités peuvent permettre à un attaquant de prendre le contrôle de systèmes vulnérables, d'accéder à des données sensibles ou de perturber leur fonctionnement. Il est donc essentiel de maintenir PHP à jour et d'appliquer rapidement les correctifs de sécurité.

Consulter l'alerte Cybermalveillance.gouv.fr ↗

🪟 Les vulnérabilités Windows et Active Directory

Windows Server et Active Directory sont largement utilisés dans les entreprises pour administrer les ordinateurs, les utilisateurs et les droits d'accès. Des vulnérabilités peuvent affecter ces environnements et permettre, selon les failles, une élévation de privilèges, un accès non autorisé ou une perturbation des services. Il est donc important de suivre les bulletins de sécurité Microsoft, d'appliquer les correctifs et de protéger les comptes administrateurs.

Consulter les mises à jour de sécurité Microsoft ↗
